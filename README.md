## ⚡ Overview

A lightweight, high-performance personal portfolio built with pure semantic HTML5, modern CSS3 custom properties, and vanilla JavaScript. Designed with a minimal, typography-driven aesthetic featuring:

- **Solo Profile Showcase**: Prominent first-stage presentation with high-resolution portrait, status pill, and personal narrative.
- **Theme Engine**: Built-in `Light`, `Dark`, and `System` theme switching with `localStorage` persistence and crossfade transitions.
- **Interactive Experience & Credentials**: Event history featuring the **AppBuilders PH Hackathon** with an accessible credential viewer modal.
- **Responsive Layout**: Fixed left navigation sidebar on desktop (≥1024px) and a sticky backdrop-blur header with fullscreen overlay on mobile (<1024px).
- **Zero Build Tools**: No `npm`, no bundler, no framework dependencies—runs natively in any modern web browser.

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5 (ARIA landmarks, accessible forms, modal dialogs)
- **Styling**: Modern CSS3 (Custom properties/tokens, CSS Grid, Flexbox, Halftone SVG masks)
- **Scripting**: Vanilla JavaScript (ES6+, IntersectionObserver, theme and modal controllers)
- **Typography**: Google Fonts (`Geist`, `Geist Mono`, `Source Serif 4`)
- **Hosting**: GitHub Pages

## 🚀 Running Locally

No installation or server setup is required:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/aeronautic005/portfolio.git
   ```
2. Navigate into the folder:
   ```bash
   cd portfolio
   ```
3. Open `index.html` directly in your browser, or launch it with a local static server / VS Code Live Server.
